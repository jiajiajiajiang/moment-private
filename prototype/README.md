# 片刻私人记忆空间

这不是只读展示页：登录后可新增文字与多张照片、选择事件时间和世界城市、写入标签与心情，并从 Supabase 重新读取个人记忆。

地点选择根据访问环境自动切换：在中国大陆（东八区时区，且配置了 `AMAP_KEY`）自动启用高德 JS API（真实瓦片地图 + POI 搜索 + 点击选点逆地理）；外网环境自动启用 Leaflet + OpenStreetMap（Nominatim 地名搜索 + 点击逆地理）。全部失败时回退到随网页部署的 GeoNames 离线城市库与内置 SVG 世界地图（含约 3.4 万座城市及多语言别名），保证离线和受限网络下仍可用，且始终不请求浏览器定位。创建记忆时可多选照片、拖拽排序、设置封面、单张删除与继续追加。

## 已接通的页面交互

- 首页真实记忆流、照片/地点筛选和随机回忆；
- 创建、编辑、修改历史、多图上传、自定义心情和城市地图；
- 时间轴、年度统计、全文/标签/地点/心情搜索和照片墙；
- 动态详情、多图切换、回忆屏蔽、系统分享摘要；
- 原图不重新压缩上传、按原始比例展示，并支持从私人存储下载原文件；
- 竖图和超宽图采用视口高度限制与完整包含显示，不裁切画面，也不会无限拉长页面；
- 分享面板支持可靠复制、系统分享和 TXT 摘要下载；
- 归档、回收站、恢复及二次确认后的永久删除；
- 个人资料、JSON 数据导出、修改密码和退出登录；
- 使用 AES-GCM 在浏览器端加密的未来信箱。

已有 Supabase 项目升级时，请先在 SQL Editor 中运行 `../database/interaction-upgrade.sql`，再部署网页文件。

这是一个无构建依赖的响应式可点击原型，覆盖：

- 单一主人账户密码登录与液态玻璃动态背景；
- 首页个人记忆流；
- 创建多媒体记忆；
- 时间轴；
- 记忆搜索、标签与照片墙；
- 个人中心、归档和回收站入口；
- 记忆详情与随机回忆屏蔽。

直接使用浏览器打开 `index.html` 即可。原型使用演示数据，不会上传或保存真实内容。

## 关键交互

- 桌面端左侧导航、移动端底部导航可切换页面；
- 点击记忆卡片或照片进入详情；
- 点击“记录此刻”进入创建页；
- 选择本地图片只触发原型状态，不会真正读取或上传；
- 保存、搜索和屏蔽回忆会显示反馈。
- 登录页会调用 Supabase 密码认证，并支持登录后验证当前密码、自主修改新密码。
