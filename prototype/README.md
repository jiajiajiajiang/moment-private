# 片刻私人记忆空间

这不是只读展示页：登录后可新增文字与多张照片、选择事件时间和世界城市、写入标签与心情，并从 Supabase 重新读取个人记忆。

地点选择使用随网页部署的 GeoNames 离线城市库和内置世界地图，包含约 3.4 万座城市及多语言别名。搜索不依赖境外地图服务、不请求浏览器定位，也不会上传城市关键词，适用于中国大陆网络环境。

## 已接通的页面交互

- 首页真实记忆流、照片/地点筛选和随机回忆；
- 创建、编辑、修改历史、多图上传、自定义心情和城市地图；
- 时间轴、年度统计、全文/标签/地点/心情搜索和照片墙；
- 动态详情、多图切换、回忆屏蔽、系统分享摘要；
- 原图不重新压缩上传、按原始比例展示，并支持从私人存储下载原文件；
- 竖图和超宽图采用视口高度限制与完整包含显示，不裁切画面，也不会无限拉长页面；
- 分享面板支持可靠复制、系统分享和 TXT 摘要下载；
- 归档、回收站、恢复及二次确认后的永久删除；
- 个人资料、JSON 数据导出、修改密码和退出登录；
- 使用 AES-GCM 在浏览器端加密的未来信箱。

已有 Supabase 项目升级时，请先在 SQL Editor 中运行 `../database/interaction-upgrade.sql`，再部署网页文件。全新项目执行 `../database/schema.sql` 即可。

## 运行要求

- 完整功能需要通过 HTTP(S) 访问，不能依赖直接双击 `index.html`；
- `config.js` 需要提供 Supabase Project URL、Publishable key 和唯一主人邮箱；
- 不得在网页配置中填写 Secret key、`service_role` key 或主人密码；
- GitHub Actions 部署时会自动生成公开运行配置，并只发布本目录；
- 数据安全依赖 Supabase Auth、RLS 和私有 `memory-media` Storage Bucket。

完整部署、更新、安全和当前功能说明请查看仓库根目录的 `README.md`。
